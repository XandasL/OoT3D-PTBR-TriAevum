Tradução PT-BR para Ocarina of Time 3D / TriAevum — v1.3.0

Pré-release para TriAevum v0.8.0-beta.1.1.
Faça backup dos seus saves antes de atualizar a instalação.

Compatibilidade: base de dados beta.1.1 validada no Windows x64.
Linux: pacote disponível para testes; validação no jogo pendente.

Escolha a fonte:
• Original: não instala nossa cobertura HD e preserva fontes de terceiros.
• HD 128: usa a fonte desenvolvida para este projeto, com as métricas originais.
A escolha pode ser alterada depois sem reinstalar a tradução.

Windows: abra o instalador .exe. Linux: conceda permissão de execução ao
instalador (chmod +x) e execute-o fora do AppImage/Flatpak do jogo.
Prepare o jogo no Forge, feche o jogo e selecione a pasta que contém
TriAevum.launch.json e data. Verifique o status, escolha a fonte e instale.
O instalador aplica a tradução completa, incluindo textos nas texturas originais,
preserva os arquivos originais e cria um
perfil de dados traduzidos. Não altera saves, FPS, resolução nem iluminação.
Para desinstalar, use Restaurar original. Preserve o recibo e os backups.
Se usa uma tradução antiga, restaure-a com o instalador correspondente antes
de instalar esta versão. Não instale por cima de dados modificados.

Texturas HD são opcionais e instaladas pelo próprio usuário no TriAevum.
Para Henriko, use o pack original no diretório load de texturas do TriAevum
e ative o carregamento de texturas personalizadas nas configurações do jogo.
Para o Henriko original 5.0a, o download opcional de compatibilidade da release
contém um pack.json com 71 aliases. Preserve o pack.json anterior, copie o novo
para a raiz do pack (ao lado de UI) e selecione essa raiz no TriAevum,
terminando em user/load/textures/0004000000033500. Reabra o jogo.
Este instalador não procura, copia, combina nem modifica packs de texturas.
Sem pack HD, as texturas nativas continuam traduzidas. A tradução de texturas
não é automaticamente transferida para arquivos de packs HD de terceiros.
Os diálogos e demais mensagens continuam em português, com a fonte escolhida.

Tradução original: Projeto Zelda Brasil – Heroes of Time; Catatau Game Dev e
Traduções; Elite dos Quatro Traduções; JumpManClub Brasil Traduções; TRADU-ROMS.
Port, adaptação e empacotamento: XandasL.
Distribuição da tradução autorizada pelo responsável, com os devidos créditos.
Nenhuma ROM, executável do jogo, fonte QBF nativa ou pack de texturas é incluído.
Projeto de fãs, sem afiliação oficial com a Nintendo.
Recuperação: se a operação for interrompida, abra o instalador e clique em
Instalar / aplicar fonte novamente. A recuperação é automática antes de instalar.
Restaurar original também verifica e recupera operações anteriores.
Só estados verificáveis serão retomados.
Se o perfil, a fonte ou os dados foram alterados por terceiros, a recuperação
é bloqueada e os arquivos são preservados. Temporários ilegíveis precisam de
revisão manual: não apague backups para forçar a instalação.
Os journals concluídos ficam em data/mods/ptbr-recovery para auditoria.
Os testes simulam interrupções de processo; não certificam perda física de
energia, falhas do disco ou durabilidade de hardware no Windows.
