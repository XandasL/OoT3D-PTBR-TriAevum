# Ocarina of Time 3D — Tradução PT-BR para TriAevum

Port completo da tradução brasileira de The Legend of Zelda:
Ocarina of Time 3D para execução através do TriAevum.

## Características

- Diálogos traduzidos para PT-BR
- Menus e interface traduzidos
- Texturas e elementos gráficos traduzidos
- Compatibilidade com a interface TopScreen / Single Screen
- Instalador automático
- Sistema de backup e restauração dos arquivos originais

## Instalação

1. Tenha uma instalação funcional e compatível do TriAevum.
2. Baixe a versão mais recente na seção Releases.
3. Coloque o instalador na pasta principal do TriAevum.
4. Execute o instalador.
5. Clique em **Instalar tradução**.
