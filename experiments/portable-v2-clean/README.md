# OoT3D PT-BR v2 — classic-only portable prototype

The clean variant intentionally excludes all edited Vanilla UI/HUD and TopScreen HD assets, respecting the upstream author's no-redistribution request. It uses only the classic O3RO with 126 replacements. The portable package generator takes an already validated local O3RO as input, and never downloads or bundles third-party HD textures. It preserves Forge-selected graphics settings, so any originally configured HD texture pack may still contain English image text.

The development-only source bundle is distributed separately to the author. **No O3RO or modified HD PNG is committed here.** The O3RO contains game-derived material and its distribution rights must be reviewed before public release.

Target: TriAevum `v0.8.0-beta.1.2`. The clean-only package has been checked structurally but is **not yet validated in-game as the final clean package**. The underlying classic overlay was previously validated in-game.
